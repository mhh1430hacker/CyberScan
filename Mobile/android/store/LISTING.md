## English (en-US)

**App name:** CyberScan: File & Link Checker

**Short description:**
Check files, links and text before you open them. Runs on your phone, offline.

**Full description:**

CyberScan shows you what's inside a file before you open it — and it does the work on your phone. Nothing is uploaded.

Got an "invoice.pdf.exe" in a chat? A strange link? A script someone asked you to paste? Share it to CyberScan, or pick it in the app, and get a plain answer in seconds: clear, worth a review, or suspicious — with every finding explained in simple words, in English or Arabic.

WHAT IT CHECKS
• Files of any kind: Windows programs, scripts, documents, archives and more
• Links, before you tap them
• Pasted text: commands, scripts and messages

HOW IT DECIDES
• Reads every byte without ever running the file
• Real file type versus the name and extension it claims
• Randomness map of the file, to spot packed or encrypted parts
• Known-pattern rules (YARA)
• Program anatomy: sections, unusual imports, hidden data after the end of the file
• Archive contents
• Mapping to MITRE ATT&CK techniques
• One score, never lower than the strongest clue — and it says so when it isn't sure

MORE THAN A VERDICT
• Repair a copy: remove the parts that don't belong in the file's format; your original stays untouched
• Check many files at once
• SHA-256, SHA-1 and MD5 fingerprints, one tap to copy
• Export a report as a web page, text or JSON, or share it
• History with search, filters and a 14-day overview — kept only on your phone

BUILT FOR ANDROID
• Share → CyberScan from any app, one file or many
• Open with → CyberScan from your file manager
• Shortcuts on the app icon and a Quick Settings tile: "Check copied link"
• App lock with your fingerprint, face or screen lock
• Hide from screenshots and the recent-apps preview
• Works fully offline

PRIVATE BY DESIGN
No account, no ads, no analytics, no tracking. The analysis runs on the device. Optional lookups in public threat lists (MalwareBazaar, URLhaus, ThreatFox, AlienVault OTX) are off by default; if you turn them on with your own free key, only the file's fingerprint or the link is sent — never the file.

CyberScan is a static-analysis tool that helps you decide. It doesn't replace an antivirus, and no tool can prove a file is safe.

## العربية (ar)

**اسم التطبيق:** CyberScan: فحص ملفات وروابط

**الوصف المختصر:**
افحص الملفات والروابط والنصوص قبل فتحها. يعمل على هاتفك ودون اتصال.

**الوصف الكامل:**

يُريك CyberScan ما بداخل الملف قبل أن تفتحه — ويقوم بالعمل على هاتفك. لا يُرفع أي شيء.

وصلك «invoice.pdf.exe» في محادثة؟ رابط غريب؟ سكربت طلب منك أحدهم لصقه؟ شاركه مع CyberScan أو اختره من التطبيق، واحصل على جواب واضح خلال ثوانٍ: سليم، أو يستحق المراجعة، أو مشبوه — مع شرح كل ما وُجد بكلمات بسيطة، بالعربية أو الإنجليزية.

ما الذي يفحصه
• الملفات بكل أنواعها: برامج Windows والسكربتات والمستندات والأرشيفات وغيرها
• الروابط قبل أن تضغط عليها
• النصوص الملصوقة: الأوامر والسكربتات والرسائل

كيف يقرّر
• يقرأ كل بايت دون أن يشغّل الملف أبدًا
• نوع الملف الحقيقي مقابل الاسم والامتداد الذي يدّعيه
• خريطة عشوائية لأجزاء الملف لكشف المحتوى المحزوم أو المشفّر
• قواعد الأنماط المعروفة (YARA)
• بنية البرامج: الأقسام والاستدعاءات غير المعتادة والبيانات المخفية بعد نهاية الملف
• محتويات الأرشيفات
• ربط ما يجده بتقنيات MITRE ATT&CK
• درجة واحدة لا تقل أبدًا عن أقوى دليل — ويخبرك حين لا يكون متأكدًا

أكثر من مجرد حكم
• أصلح نسخة: أزل الأجزاء التي لا تنتمي إلى صيغة الملف؛ ملفك الأصلي يبقى كما هو
• افحص عدة ملفات دفعة واحدة
• بصمات SHA-256 وSHA-1 وMD5 تُنسخ بلمسة
• صدّر التقرير صفحة ويب أو نصًا أو JSON، أو شاركه
• سجل مع بحث وتصفية وملخص لآخر 14 يومًا — محفوظ على هاتفك فقط

مصمم لـ Android
• مشاركة ← CyberScan من أي تطبيق، لملف أو عدة ملفات
• فتح باستخدام ← CyberScan من مدير الملفات
• اختصارات على أيقونة التطبيق وزر في الإعدادات السريعة: «افحص الرابط المنسوخ»
• قفل التطبيق بالبصمة أو الوجه أو قفل الشاشة
• إخفاء من لقطات الشاشة ومعاينة التطبيقات الأخيرة
• يعمل بالكامل دون اتصال

الخصوصية أولًا
لا حساب ولا إعلانات ولا تحليلات ولا تتبّع. التحليل يجري على الجهاز. البحث الاختياري في قوائم التهديدات العامة (MalwareBazaar وURLhaus وThreatFox وAlienVault OTX) مُطفأ افتراضيًا؛ وإذا شغّلته بمفتاحك المجاني تُرسل بصمة الملف أو الرابط فقط — وليس الملف أبدًا.

CyberScan أداة تحليل ثابت تساعدك على القرار. لا تحل محل برنامج مكافحة الفيروسات، ولا توجد أداة تستطيع إثبات أن ملفًا آمن.

## Data safety form (Play Console › App content › Data safety)

| Question | Answer |
|---|---|
| Does your app collect or share any of the required user data types? | **Yes**, to be safe — only because of the optional lookups (below). Play exempts transfers the user starts and expects, so "No" is arguable, but declaring it costs nothing and avoids a rejection. |
| Is all of the user data collected by your app encrypted in transit? | **Yes** (HTTPS only) |
| Do you provide a way for users to request that their data is deleted? | **Yes** — Settings › Erase all app data; nothing is kept off the device |
| Data type | **App activity › Other user-generated content** (a file fingerprint or a link the user chose to look up) |
| Collected / shared | **Shared** with the threat-list service the user chose (abuse.ch, AlienVault OTX); **not collected** by the developer |
| Optional? | **Yes**, off by default; the user turns it on and supplies their own key |
| Purpose | **App functionality** (checking an indicator against public threat lists) |
| Processed ephemerally? | Yes on the app's side; the receiving service's own policy applies |

Everything else — files, text, history, settings — is processed **on the device only**, which Play does
not count as collection.
