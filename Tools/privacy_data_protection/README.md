## What each tool does

**071 EXIF Metadata Analyzer** - Lists privacy-relevant image metadata: GPS location, device serial numbers, owner names, timestamps, software, embedded thumbnails and XMP/IPTC/comment blocks (JPEG, PNG, WebP, TIFF).

Data handling: The image is parsed in memory and never stored. GPS coordinates in the result are rounded to about 1 km. External: None. Timeout: 15 s. Source: CyberScan original implementation; Pillow (MIT-CMU) decodes EXIF values.

**072 PII Detector** - Detects personal data (emails, cards, IBANs, SSNs, Saudi IDs, UK NINOs, phones, IPs, birth dates, passports) with checksum validation where one exists, and reports masked samples, counts and line numbers.

Data handling: Text is scanned in memory; detected values are masked in the result and never stored. External: None. Timeout: 20 s. Source: CyberScan original implementation.

**073 Sensitive Data Detector** - Assigns a sensitivity level to text from classification markings (English and Arabic) and sensitive content categories: health, financial, HR, legal privilege, credentials and personal data.

Data handling: Text is scanned in memory; only categories, counts and line numbers are reported. External: None. Timeout: 20 s. Source: CyberScan original implementation.

**074 API Key Exposure Detector** - Detects exposed API keys and tokens for 30+ providers in text and reports masked previews, fingerprints and lines. Keys are never validated against providers.

Data handling: Text is scanned in memory; key values are masked and fingerprinted, never returned or stored. External: None: keys are never sent to providers for validation. Timeout: 20 s. Source: CyberScan original implementation; reuses detection.secrets.scan_secrets (frozen engine).

**075 Credential Exposure Detector** - Detects exposed passwords and private keys: PEM/SSH keys, service-account keys, credentials in connection strings and URLs, Basic auth, .netrc, htpasswd, unattend.xml and hard-coded password assignments.

Data handling: Text is scanned in memory; credentials are masked and fingerprinted, never returned or stored. External: None. Timeout: 20 s. Source: CyberScan original implementation; reuses detection.secrets.scan_secrets (frozen engine).

**076 Log Privacy Analyzer** - Scans log files for credentials, tokens, session cookies, secrets in query strings, logged passwords, personal data and stack traces, and suggests masking patterns. Values are masked in the output.

Data handling: Log lines are scanned in memory; only categories, counts, line numbers and masked samples are returned. External: None. Timeout: 30 s. Source: CyberScan original implementation.

**077 Cookie Tracking Analyzer** - Identifies tracking cookies (bundled vendor list), third-party and long-lived cookies, and missing Secure/HttpOnly/SameSite protection on session cookies, from Set-Cookie headers, HAR files or cookies.txt.

Data handling: Cookie names and attributes are analysed in memory; cookie values are never returned. External: None. Timeout: 20 s. Source: CyberScan original implementation; tracker names from vendors' cookie documentation (snapshot 2026-11-10).

**078 Browser Privacy Analyzer** - Audits Chromium Preferences/Local State and Firefox prefs.js for disabled Safe Browsing, third-party cookies, disabled tracking protection, password-leak detection, DNS-over-HTTPS and site permissions granted by default.

Data handling: Only setting values are read; history, cookies and saved passwords are never opened. External: None. Timeout: 15 s. Source: CyberScan original implementation.

**079 Data Leakage Detector** - Pre-sharing check for text, DOCX/XLSX/PPTX and PDF: secrets, personal data, internal host names and paths, author/company metadata, comments, tracked changes, hidden text, embedded objects and old PDF revisions.

Data handling: Content is analysed in memory; secrets and personal data are masked in the result. External: None. Timeout: 30 s. Source: CyberScan original implementation.

**080 Metadata Removal Validator** - Checks that metadata was actually stripped from an image, Office document or PDF, and (given the original) lists what was removed and what remains. Pass/fail per check.

Data handling: Both files are parsed in memory; metadata values are summarised, not stored. External: None. Timeout: 20 s. Source: CyberScan original implementation.
