## What each tool does

**091 Cloud Configuration Analyzer** - Audits exported AWS, Azure and GCP configuration JSON (security groups/NSGs/firewall rules, instances, databases, volumes, CloudTrail, storage accounts, Cloud SQL) for exposure, missing encryption and logging gaps. Offline only.

Data handling: Configuration exports are analysed in memory. External: None. No cloud credentials are needed or accepted; nothing is queried. Timeout: 30 s. Source: CyberScan original implementation; checks follow CIS AWS/Azure/GCP Foundations benchmark items.

**092 Public Storage Exposure Checker** - Checks S3 bucket policies/ACLs/Block Public Access, Azure container access and GCS IAM for public exposure, and optionally confirms anonymous listing with one request to an authorized bucket URL.

Data handling: Policies and ACLs are analysed in memory. External: Only with probe_url and authorization_confirmed: one anonymous HTTPS GET to that URL. Timeout: 20 s. Source: CyberScan original implementation.

**093 IAM Configuration Auditor** - Audits AWS IAM policies and trust policies (admin wildcards, privilege-escalation paths), the AWS credential report (root keys, missing MFA, old keys), Azure role definitions and GCP IAM bindings.

Data handling: Policies and the credential report (user names, dates; no secrets) are analysed in memory. External: None. No credentials are needed; nothing is queried. Timeout: 30 s. Source: CyberScan original implementation; escalation paths from public AWS IAM privilege-escalation research.

**094 Infrastructure-as-Code Scanner** - Scans Terraform and CloudFormation templates for open security groups, public storage, missing encryption, public databases, IMDSv1 and over-privileged IAM, using the same rules as the cloud configuration tools.

Data handling: Templates are parsed in memory and never applied or evaluated. External: None. Timeout: 60 s. Source: CyberScan original implementation; PyYAML (MIT) for CloudFormation YAML.

**095 Container Configuration Analyzer** - Audits Dockerfiles and docker-compose files for unpinned images, root users, secrets in layers, curl|sh, privileged containers, host namespaces, Docker-socket and host mounts, capabilities and exposed databases.

Data handling: Files are parsed in memory; images are not pulled or built. External: None. Timeout: 30 s. Source: CyberScan original implementation; checks follow the CIS Docker Benchmark.

**096 Kubernetes Configuration Auditor** - Checks Kubernetes manifests against Pod Security Standards (privileged, host namespaces, hostPath, capabilities, root, seccomp) plus RBAC wildcards, anonymous bindings, inline secrets, resource limits and exposed services.

Data handling: Manifests are parsed in memory; no cluster is contacted. External: None. Timeout: 30 s. Source: CyberScan original implementation; Kubernetes Pod Security Standards (baseline/restricted).

**097 Git Repository Security Scanner** - Checks a Git repository for credentials in remote URLs, insecure remotes/submodules, sslVerify=false, plaintext credential helpers, active hooks, committed keys/.env/tfstate/dumps, .gitignore gaps and secrets in files.

Data handling: Repository files are read in memory; secret values are masked. git is never executed. External: None: remotes are not contacted. Timeout: 90 s. Source: CyberScan original implementation.

**098 CI/CD Configuration Analyzer** - Checks GitHub Actions, GitLab CI and Jenkinsfiles for pwn-request triggers, script injection, unpinned actions, over-broad token permissions, leaked secrets, self-hosted runner exposure and unsafe shell steps.

Data handling: Pipeline files are parsed in memory. External: None. Timeout: 30 s. Source: CyberScan original implementation; follows GitHub's 'Security hardening for GitHub Actions' guidance.

**099 Backup Configuration Auditor** - Audits backup policies (generic JSON/YAML or AWS Backup plans/vaults) for 3-2-1 compliance, encryption, immutability, retention, frequency, failing jobs, untested restores and embedded credentials.

Data handling: Backup configuration is analysed in memory; secrets in it are masked. External: None. Timeout: 20 s. Source: CyberScan original implementation; 3-2-1 rule and NIST SP 800-209 / CISA ransomware guidance.

**100 Cloud Asset Exposure Analyzer** - Maps internet exposure across a cloud asset inventory (public IPs, load balancers, open admin/database ports, plain HTTP, missing owners) and finds dangling DNS records pointing at cloud hostnames no longer owned.

Data handling: The inventory is analysed in memory; nothing is resolved or contacted. External: None. Timeout: 30 s. Source: CyberScan original implementation; takeover-prone service suffixes from public subdomain-takeover research.
