## What each tool does

**061 Installed Software Risk Analyzer** - Flags installed software past end of support (bundled, dated lifecycle table), remote-access tools, installs in user-writable folders and unknown publishers. No CVE lookup is performed.

Data handling: The software inventory is analysed in memory. Local mode reads the Windows Uninstall registry keys only. External: None. Timeout: 20 s. Source: CyberScan original implementation; lifecycle dates from vendor lifecycle pages and endoflife.date (snapshot 2026-11-10).

**062 Startup Entry Analyzer** - Inspects Run/RunOnce and Startup-folder autostart entries (list, .reg export or local read-only) for user-writable paths, masquerading, encoded PowerShell, LOLBin abuse and unquoted paths.

Data handling: Autostart entries are analysed in memory; command-line secrets are masked in the output. External: None. Timeout: 15 s. Source: CyberScan original implementation; reuses detection.script_rules (frozen engine).

**063 Process Security Analyzer** - Analyses a process snapshot for user-writable executables, masquerading names, suspicious parent-child chains (Office -> shell), encoded/LOLBin command lines and duplicated singleton system processes.

Data handling: The process list is analysed in memory; command lines are masked in the output. External: None. Timeout: 20 s. Source: CyberScan original implementation; psutil (BSD-3) for local snapshots; reuses detection.script_rules.

**064 Firewall Configuration Checker** - Checks Windows Firewall profiles and rules (netsh), iptables-save and ufw for disabled profiles, allow-by-default inbound policy and rules exposing remote-admin or file-sharing ports to any address.

Data handling: Firewall configuration text is analysed in memory. External: None. Timeout: 30 s. Source: CyberScan original implementation.

**065 System Update Status Checker** - Checks OS release support (dated lifecycle tables for Windows builds and major Linux distributions), age of the newest installed Windows hotfix, and pending apt security updates.

Data handling: OS version and update lists are analysed in memory. External: None. Timeout: 15 s. Source: CyberScan original implementation; lifecycle dates from Microsoft, Ubuntu, Debian and endoflife.date (snapshot 2026-11-10).

**066 Local Permission Analyzer** - Flags world-writable files and folders, setuid/setgid binaries, private keys readable by others and Windows ACLs that let broad groups modify files, from ls -l/icacls output or a read-only walk of listed paths.

Data handling: Only file names and permission metadata are read; file contents are never opened. External: None. Timeout: 30 s. Source: CyberScan original implementation.

**067 Scheduled Task Analyzer** - Reviews Windows scheduled-task XML and cron tables for tasks launching from temporary folders, encoded or LOLBin commands, download-and-run cron jobs and hidden privileged tasks triggered at boot or logon.

Data handling: Task definitions are parsed in memory; command-line secrets are masked. External: None. Timeout: 30 s. Source: CyberScan original implementation; reuses detection.script_rules (frozen engine).

**068 Browser Extension Risk Analyzer** - Rates browser extensions (manifest, .crx/.zip/.xpi package or local browser profiles) for powerful permissions, all-site session access, weakened CSP, off-store updates, Manifest V2 and broad injection.

Data handling: Manifests and packages are read in memory. Local mode reads only extension manifest files in browser profiles. External: None. Timeout: 30 s. Source: CyberScan original implementation; reuses detection.archives.inspect_browser_extension (frozen engine).

**069 System Configuration Auditor** - Audits Windows registry security settings (.reg export or local read-only) and Linux kernel sysctl values against common hardening baselines: UAC, credential protection, legacy protocols, RDP, AutoRun, ASLR and more.

Data handling: Configuration values are analysed in memory. External: None. Timeout: 15 s. Source: CyberScan original implementation; checks follow Microsoft security baselines and CIS benchmark items.

**070 Persistence Configuration Auditor** - Audits Windows persistence registry points (Winlogon, IFEO, AppInit, LSA packages, services, COM hijacks...) and Linux persistence files (systemd, rc, shell profiles, authorized_keys, ld.so.preload, udev).

Data handling: Registry exports and files are analysed in memory; command-line secrets are masked. External: None. Timeout: 30 s. Source: CyberScan original implementation; mechanisms follow MITRE ATT&CK T1546/T1547/T1543/T1574.
