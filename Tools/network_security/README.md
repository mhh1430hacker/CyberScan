## What each tool does

**051 DNS Security Analyzer** - Audits SPF, DMARC, DKIM (named selectors), MX, NS redundancy, CAA and DNSSEC presence for one domain, from supplied records or passive DNS lookups. It does not probe mail servers or enumerate subdomains.

Data handling: Only the domain name and its public DNS records are processed, in memory. External: With resolve=true, DNS queries for the domain's own records go to the system or given resolver. Timeout: 20 s. Source: CyberScan original implementation; dnspython (ISC) for live lookups.

**052 DNSSEC Validator** - Validates DNSKEY self-signatures, RRSIGs on supplied RRsets and the DS-to-DNSKEY match for one zone, and flags weak algorithms or expiring signatures. Offline (zone text) or passive live queries.

Data handling: Only public DNS data for the zone is processed, in memory. External: With resolve=true, DNSKEY/DS/SOA queries for the zone go to the system or given resolver. Timeout: 20 s. Source: CyberScan original implementation; dnspython (ISC) and cryptography (Apache-2.0/BSD) for validation.

**053 Network Configuration Analyzer** - Audits sshd_config and Cisco IOS-style device configurations for weak authentication, cleartext management, default SNMP communities, weak ciphers and missing hardening. Text analysis only; nothing is contacted.

Data handling: The configuration text is analysed in memory; secrets in it are masked in the output. External: None. Timeout: 10 s. Source: CyberScan original implementation.

**054 Public IP Reputation Checker** - Classifies IP addresses (private, reserved, bogon, documentation, CGNAT, multicast) and matches them against user-supplied CIDR blocklists and allowlists. No built-in or online reputation feed is used.

Data handling: Addresses and lists are matched in memory; nothing is sent anywhere. External: None. Online reputation services are deliberately not queried. Timeout: 15 s. Source: CyberScan original implementation; special-purpose ranges from the IANA IPv4/IPv6 Special-Purpose Address Registries.

**055 Authorized Service Exposure Checker** - Flags risky listening services from a netstat/ss listing, or TCP-connect-checks a small set of ports on hosts you are authorized to test. Connect only: no payloads, banner grabbing, brute force or exploitation.

Data handling: Socket listings are parsed in memory. Probe mode only opens and closes TCP connections. External: Probe mode connects to the hosts you list; listing mode contacts nothing. Timeout: 30 s. Source: CyberScan original implementation.

**056 Network Traffic Metadata Analyzer** - Reads pcap/pcapng captures (headers and DNS question names only), builds flows and flags cleartext protocols, port scans, periodic beaconing, DNS tunnelling patterns and unusual outbound volume.

Data handling: The capture is parsed in memory; only header fields and DNS names are used, payloads are discarded. External: None. Timeout: 30 s. Source: CyberScan original implementation (pcap/pcapng parsing with the Python standard library).

**057 Certificate Chain Validator** - Validates a TLS certificate chain (PEM or from one handshake): trust path, signatures, dates, host name, key sizes, SHA-1/MD5 signatures and CA constraints.

Data handling: Certificates are public data and are parsed in memory. External: Only when 'host' is given: one TLS handshake to that host and port. Timeout: 20 s. Source: CyberScan original implementation; cryptography (Apache-2.0/BSD) and certifi (MPL-2.0) trust store.

**058 HSTS Configuration Checker** - Checks the Strict-Transport-Security header (syntax, max-age, includeSubDomains, preload readiness, duplicates, delivery over HTTP) from pasted headers or one passive request to a named URL.

Data handling: Response headers are parsed in memory; response bodies are not kept. External: Only with 'url': one HTTPS request (and one HTTP request if check_http_redirect). Timeout: 20 s. Source: CyberScan original implementation (RFC 6797; hstspreload.org submission requirements).

**059 MTA-STS Validator** - Validates the MTA-STS TXT record and policy (version, mode, mx patterns, max_age), checks that MX hosts match the policy and that TLS-RPT reporting is configured. Offline or passive DNS/HTTPS lookups.

Data handling: Public DNS records and the public policy file are processed in memory. External: Live mode: DNS queries for the domain, and one HTTPS GET of its policy file if fetch_policy. Timeout: 25 s. Source: CyberScan original implementation (RFC 8461, RFC 8460); dnspython (ISC) for live lookups.

**060 Network Anomaly Analyzer** - Finds scans, sweeps, beaconing, DNS tunnelling and unusual outbound volume in exported flow records (JSON, CSV or Zeek conn.log). Behavioural heuristics, not confirmed compromise.

Data handling: Flow records (addresses, ports, byte counts) are analysed in memory. External: None. Timeout: 30 s. Source: CyberScan original implementation.
