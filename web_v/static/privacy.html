Privacy policyسياسة الخصوصية

CyberScan is built to know as little about you as possible. This page says exactly what it reads, what it keeps and who else is involved.صُمّم CyberScan ليعرف عنك أقل قدر ممكن. توضح هذه الصفحة بدقة ما الذي يقرؤه، وما الذي يحتفظ به، ومن الجهات الأخرى المشاركة.

Last updated: 25 November 2026آخر تحديث: 25 نوفمبر 2026

The short version

  • No accounts, no sign-in, no ads, no trackers, no analytics companies.
  • A file you check on this website is sent to CyberScan's server, read in memory and deleted as soon as the check ends. It is never run, and no copy or history is kept on the server.
  • Your scan history stays in your own browser; you can clear it at any time.
  • The desktop and Android apps check files on your own device.
  • A website scan also asks outside threat-intelligence services such as VirusTotal using only the file's fingerprint or the link, never the file; you can switch this off for any scan (details).

What CyberScan reads

Only what you give it: a file you drop or choose, a link you paste, or text you paste. CyberScan reads the bytes of that input (static analysis: file type, structure, entropy, signatures, known patterns, YARA rules). It does not open, execute or render the file.

On the website, files are limited to 4 MB. The upload goes over HTTPS to the server, is written to a temporary folder only for the check and deleted when the check ends (also when it fails or times out).

Links are analysed as text (their shape and known lists of bad domains); CyberScan does not visit them for you. Unless you switch it off, the link is also looked up with outside services (see External threat-intelligence lookups).

What the server keeps

  • No scan history, no files, no reports. Results are sent back to your browser only.
  • No IP addresses in CyberScan's own logs. The server does not write a request log. The free AI questions are limited per visitor per day; to do that, the address is held in memory only, and forgotten when the server instance stops.
  • Anonymous performance and error numbers. To keep the site fast and fix bugs, about 1 in 5 page views send loading-speed measurements (LCP, INP, CLS, TTFB), and pages send script error messages (message, file and line only, at most a few per page). These contain no IP address, no identifiers, no cookies and nothing you typed; anything that looks like an email address or a long number is removed before it is stored.
  • Our hosting provider (AWS) keeps its own operational records (for example, that a request was handled, how long it took, and errors) as part of running the service.

Cookies and browser storage

CyberScan sets one cookie: cs-audio, which remembers your sound preferences (music on or off, volume, sound effects). It is shared by ainex-ai.xyz and its scan. and j. pages so the music settings follow you, and it expires after one year. It is not used for tracking.

In your browser's local storage the site keeps: your language (cyberscan-lang), whether you have chosen it, reduce-motion, light-mode and accessibility choices, and your own scan history on the scan page. None of it is sent to the server.

Third parties

  • Amazon Web Services (AWS) hosts the website (Lambda, S3 and CloudFront, region eu-north-1, Stockholm).
  • Amazon Bedrock (AWS) answers questions in “Ask the AI”, only when you use it. Your question and the conversation so far are sent to the model; scan files are not. AWS does not use Bedrock inputs to train models.
  • Have I Been Pwned, only when you use the password check: your browser sends the first 5 characters of the password's SHA-1 hash (k-anonymity), never the password.
  • YouTube, only where a page shows a video: it uses the privacy-enhanced youtube-nocookie.com player, which contacts YouTube only when you press play.

External threat-intelligence lookups

To tell you whether the wider security community already knows what you are checking, a website scan also asks outside threat-intelligence services, by default, with a switch just above the Start button to turn it off (your choice is remembered in your browser as cs-external-intel). These are lookups only: CyberScan never uploads your file and never submits anything for scanning, so CyberScan adds nothing new to these services' databases.

What is sent, and to whom:

  • For a file: only its SHA-256 fingerprint (a 64-character code computed from the file; the file cannot be rebuilt from it), to VirusTotal (Google; how many antivirus engines flag it), MalwareBazaar (abuse.ch; known malware samples) and CIRCL hashlookup (Luxembourg's CERT; known, legitimate software). The file's name and contents are never sent.
  • For a link: the link itself to VirusTotal, Google Safe Browsing and URLhaus (abuse.ch), and only its host name (for example example.com) to VirusTotal's site report, AlienVault OTX (LevelBlue) and urlscan.io (only searched for existing public scans; CyberScan never asks it to visit the link). Links to private or local addresses are not sent anywhere.
  • Pasted text is not sent to any of these services.

The requests come from CyberScan's server, not from your browser, so these services see the server's address, not yours, and no cookie or identifier of yours. A service is asked only when the site operator has set up a key for it (CIRCL needs none); the result card says which services answered and which are not configured. Answers (the services' numbers, not your link) are cached for up to 6 hours, in memory and in the site's own storage on AWS, under a one-way code of what was looked up, so repeated checks don't spend the services' free quotas. To protect those quotas, the number of scans with online lookups is limited per visitor; the visitor's address is held in memory only for that, and forgotten when the server instance stops.

Each service handles what it receives under its own privacy policy: VirusTotal (Google), Google Safe Browsing (Google), abuse.ch (URLhaus, MalwareBazaar), CIRCL, AlienVault OTX (LevelBlue) and urlscan.io. If a link is private (for example it contains a password-reset token), switch the lookups off before you check it.

In the desktop app the same lookups stay off until you turn them on in Settings, and use keys you enter yourself.

Your choices and rights

Because CyberScan does not know who you are, there is no profile to access or delete. You can clear the site's cookie and storage in your browser at any time. For any question about privacy, write to mahdi-alhajji@zohomail.sa.

The site is not directed at children under 13 and does not knowingly collect information from anyone.

If this policy changes, the new version will be published on this page with a new date, and listed in the changelog.

باختصار

  • لا حسابات ولا تسجيل دخول ولا إعلانات ولا أدوات تتبّع ولا شركات تحليلات.
  • الملف الذي تفحصه على هذا الموقع يُرسل إلى خادم CyberScan، ويُقرأ في الذاكرة ثم يُحذف فور انتهاء الفحص. لا يُشغَّل أبدًا، ولا تُحفظ منه نسخة ولا سجل على الخادم.
  • سجل فحوصاتك يبقى في متصفحك أنت، ويمكنك مسحه متى شئت.
  • تطبيقا سطح المكتب وأندرويد يفحصان الملفات على جهازك نفسه.
  • يسأل الفحص على الموقع أيضًا خدمات خارجية لمعلومات التهديدات مثل VirusTotal ببصمة الملف أو الرابط فقط، لا الملف أبدًا؛ ويمكنك إيقاف ذلك لأي فحص (التفاصيل).

ما الذي يقرؤه CyberScan

ما تعطيه إياه فقط: ملف تسقطه أو تختاره، أو رابط تلصقه، أو نص تلصقه. يقرأ CyberScan بايتات هذا المُدخل (تحليل ساكن: نوع الملف وبنيته والإنتروبيا والتواقيع والأنماط المعروفة وقواعد YARA)، ولا يفتح الملف ولا يشغّله ولا يعرضه.

على الموقع، الحد الأقصى للملف 4 ميغابايت. يصل الملف إلى الخادم عبر HTTPS، ويُكتب في مجلد مؤقت لأجل الفحص فقط، ويُحذف عند انتهاء الفحص (وكذلك إذا فشل أو انتهت مهلته).

الروابط تُحلَّل كنص (شكلها وقوائم معروفة للنطاقات الضارة)، ولا يزورها CyberScan نيابة عنك. وما لم توقف ذلك، يُبحث عن الرابط أيضًا لدى خدمات خارجية (انظر البحث في مصادر معلومات التهديدات الخارجية).

ما الذي يحتفظ به الخادم

  • لا سجل فحوصات ولا ملفات ولا تقارير. تُرسل النتائج إلى متصفحك فقط.
  • لا عناوين IP في سجلات CyberScan. الخادم لا يكتب سجلًا للطلبات. أسئلة الذكاء الاصطناعي المجانية محدودة لكل زائر في اليوم، ولهذا يُحتفظ بالعنوان في الذاكرة فقط ويُنسى حين تتوقف نسخة الخادم.
  • أرقام أداء وأخطاء مجهولة الهوية. لإبقاء الموقع سريعًا وإصلاح الأخطاء، ترسل نحو صفحة من كل خمس قياسات سرعة التحميل (LCP وINP وCLS وTTFB)، وترسل الصفحات رسائل أخطاء البرمجة (الرسالة والملف والسطر فقط، وبضع رسائل على الأكثر لكل صفحة). لا تحتوي على عنوان IP ولا معرّفات ولا ملفات تعريف ارتباط ولا أي شيء كتبته، ويُحذف منها كل ما يشبه بريدًا إلكترونيًا أو رقمًا طويلًا قبل حفظها.
  • مزوّد الاستضافة (AWS) يحتفظ بسجلات تشغيلية خاصة به (مثل أن طلبًا عولج، وكم استغرق، والأخطاء) ضمن تشغيل الخدمة.

ملفات تعريف الارتباط وتخزين المتصفح

يضع CyberScan ملف تعريف ارتباط واحدًا: cs-audio، ويتذكر تفضيلات الصوت (تشغيل الموسيقى أو إيقافها، ومستوى الصوت، والمؤثرات الصوتية). تتشاركه صفحات ainex-ai.xyz والنطاقان scan. وj. لتتبعك إعدادات الموسيقى، وتنتهي صلاحيته بعد سنة. لا يُستخدم للتتبّع.

وفي التخزين المحلي لمتصفحك يحفظ الموقع: لغتك (cyberscan-lang)، وهل اخترتها، وخيارات تقليل الحركة والوضع الخفيف وإمكانية الوصول، وسجل فحوصاتك في صفحة الفحص. لا يُرسل شيء من ذلك إلى الخادم.

الجهات الخارجية

  • Amazon Web Services (AWS) تستضيف الموقع (Lambda وS3 وCloudFront، منطقة eu-north-1 في ستوكهولم).
  • Amazon Bedrock (من AWS) يجيب عن الأسئلة في «اسأل الذكاء الاصطناعي»، فقط حين تستخدمه. يُرسل سؤالك والمحادثة حتى الآن إلى النموذج، ولا تُرسل ملفات الفحص. لا تستخدم AWS مدخلات Bedrock لتدريب النماذج.
  • Have I Been Pwned، فقط حين تستخدم فحص كلمة المرور: يرسل متصفحك أول 5 أحرف من بصمة SHA-1 لكلمة المرور (إخفاء الهوية بالتجزئة)، ولا يرسل كلمة المرور أبدًا.
  • YouTube، فقط حيث تعرض صفحة مقطع فيديو: يُستخدم مشغّل youtube-nocookie.com المعزّز للخصوصية، ولا يتصل بـ YouTube إلا حين تضغط تشغيل.

البحث في مصادر معلومات التهديدات الخارجية

لنخبرك هل يعرف مجتمع الأمن السيبراني ما تفحصه مسبقًا، يسأل الفحص على الموقع أيضًا خدمات خارجية لمعلومات التهديدات، افتراضيًا، مع مفتاح فوق زر البدء مباشرة لإيقافه (ويتذكر متصفحك اختيارك باسم cs-external-intel). هذه استعلامات فقط: لا يرفع CyberScan ملفك أبدًا ولا يرسل أي شيء للفحص، فلا يضيف CyberScan شيئًا جديدًا إلى قواعد بيانات هذه الخدمات.

ما الذي يُرسل، وإلى من:

  • للملف: بصمة SHA-256 فقط (رمز من 64 خانة يُحسب من الملف، ولا يمكن إعادة بناء الملف منه) إلى VirusTotal (من Google؛ كم محرك مكافحة فيروسات يشير إليه)، وMalwareBazaar (من abuse.ch؛ عيّنات البرمجيات الضارة المعروفة)، وCIRCL hashlookup (فريق الاستجابة الوطني في لوكسمبورغ؛ البرامج المعروفة والموثوقة). لا يُرسل اسم الملف ولا محتواه أبدًا.
  • للرابط: الرابط نفسه إلى VirusTotal وGoogle Safe Browsing وURLhaus (من abuse.ch)، واسم المضيف فقط (مثل example.com) إلى تقرير الموقع في VirusTotal وAlienVault OTX (من LevelBlue) وurlscan.io (يُبحث فيه عن فحوص علنية سابقة فقط، ولا يطلب منه CyberScan زيارة الرابط أبدًا). الروابط إلى عناوين خاصة أو محلية لا تُرسل إلى أي جهة.
  • النص الملصق لا يُرسل إلى أي من هذه الخدمات.

تصدر الطلبات من خادم CyberScan لا من متصفحك، فترى هذه الخدمات عنوان الخادم لا عنوانك، ولا أي ملف تعريف ارتباط أو معرّف خاص بك. لا تُسأل خدمة إلا إذا أعدّ مشغّل الموقع مفتاحًا لها (CIRCL لا تحتاج مفتاحًا)، وتوضح بطاقة النتيجة أي الخدمات أجابت وأيها غير مُعدّ. تُحفظ الإجابات (أرقام الخدمات، لا رابطك) مؤقتًا حتى 6 ساعات في الذاكرة وفي تخزين الموقع نفسه على AWS، تحت رمز أحادي الاتجاه لما بُحث عنه، كي لا تستهلك الفحوص المتكررة الحصص المجانية لهذه الخدمات. ولحماية هذه الحصص يُحدّ عدد الفحوص التي تتضمن بحثًا عبر الإنترنت لكل زائر؛ ويُحتفظ بعنوان الزائر في الذاكرة لهذا الغرض فقط، ويُنسى حين تتوقف نسخة الخادم.

تتعامل كل خدمة مع ما يصلها وفق سياسة الخصوصية الخاصة بها: VirusTotal (Google)، وGoogle Safe Browsing (Google)، وabuse.ch (URLhaus وMalwareBazaar)، وCIRCL، وAlienVault OTX (LevelBlue)، وurlscan.io. إن كان الرابط خاصًا (مثلًا يحتوي رمز إعادة تعيين كلمة مرور) فأوقف هذا البحث قبل فحصه.

في تطبيق سطح المكتب يبقى هذا البحث متوقفًا حتى تفعّله من الإعدادات، ويستخدم مفاتيح تُدخلها بنفسك.
